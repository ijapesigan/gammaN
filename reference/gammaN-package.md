# gammaN: Asymptotic Covariance Matrix Under Normality

Helpers for the asymptotic covariance matrix of the sample covariance
matrix under the multivariate normal distribution, and for the sample
covariance matrix of the data. Each function has an internal version
without input checks that other projects can copy.
